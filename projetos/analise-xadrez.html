POWER BI • API • XADREZ

Análise de Partidas de Xadrez.

Projeto pessoal que transforma meu histórico de partidas no Chess.com em uma análise interativa sobre desempenho, evolução de rating, aproveitamento e comportamento ao longo do tempo.

Power BI Power Query DAX API REST JSON Chess.com

O PROJETO

Dados aplicados a um dos meus hobbies.

O xadrez é um dos meus principais hobbies e o Chess.com é a plataforma que utilizo para jogar, treinar e acompanhar minha evolução.

Neste projeto, utilizei a API pública do Chess.com para transformar meu histórico de milhares de partidas em uma solução analítica desenvolvida no Power BI.

O objetivo foi construir uma visão estruturada sobre minha evolução como jogador, permitindo analisar resultados, rating, modalidades, adversários e diferentes períodos da minha trajetória na plataforma.

O DESAFIO

Transformar partidas em informação.

O histórico de partidas contém uma quantidade significativa de informações sobre jogadores, resultados, modalidades, rating e características de cada partida.

O desafio foi consumir esses dados através da API, estruturá-los, realizar as transformações necessárias e construir indicadores capazes de apresentar minha evolução de forma clara e interativa.

IMPLEMENTAÇÃO

Como o projeto foi construído.

Além da análise visual, o projeto envolveu diferentes etapas de integração, tratamento, modelagem e publicação dos dados.

  • Integração com a API do Chess.com: utilizei a API pública da plataforma para coletar meu histórico de partidas, informações dos adversários, resultados, modalidades e dados de rating.
  • Enriquecimento dos dados com a API do World Bank: utilizei a API pública de países do Banco Mundial para construir uma dimensão de países a partir do código ISO dos adversários. Dessa forma, foi possível identificar o país de origem dos jogadores enfrentados e incluir essa informação nas análises.
  • Dimensão de países: os dados retornados pela API do World Bank foram tratados no Power Query, mantendo o código ISO de duas letras e o nome do país para relacionamento com os dados dos jogadores do Chess.com.
  • Tratamento de dados no Power Query: todo o processo de limpeza, transformação, padronização e preparação dos dados foi desenvolvido utilizando Power Query e linguagem M.
  • Modelagem de dados: os dados foram organizados e relacionados para permitir análises por período, modalidade, rating, adversário, país e resultado das partidas.
  • Medidas em DAX: foram desenvolvidas medidas para cálculo de indicadores como quantidade de partidas, vitórias, derrotas, empates, aproveitamento, evolução do rating e outras análises apresentadas no dashboard.
  • Dataflow no Power BI Service: criei um Dataflow para centralizar o processo de obtenção e transformação dos dados, com rotina de atualização automática diária.
  • Atualização automática do dashboard: o modelo semântico e o relatório no Power BI Service também possuem rotina de atualização diária, permitindo que novas partidas sejam incorporadas automaticamente às análises.
  • Publicação no Power BI Service: o dashboard foi publicado no ambiente online do Power BI para disponibilização e interação através da web.
  • Integração com o portfólio: o dashboard foi incorporado diretamente ao meu site utilizando o recurso de embed do Power BI.
  • Portfólio desenvolvido com HTML e CSS: o site foi construído e publicado através do GitHub Pages, utilizando HTML e CSS, com apoio de Inteligência Artificial durante o desenvolvimento e refinamento da interface.
