POWER BI • API • XADREZ

Análise de Partidas de Xadrez.

Projeto pessoal que transforma meu histórico de partidas no Chess.com em uma análise interativa sobre desempenho, evolução de rating, aproveitamento e comportamento ao longo do tempo.

Power BI Power Query DAX API REST JSON Chess.com

O PROJETO

Dados aplicados a um dos meus hobbies.

O xadrez é um dos meus principais hobbies e o Chess.com é a plataforma que utilizo para jogar, treinar e acompanhar minha evolução.

Neste projeto, utilizei a API pública do Chess.com para transformar meu histórico de milhares de partidas em uma solução analítica desenvolvida no Power BI.

O objetivo foi construir uma visão estruturada sobre minha evolução como jogador, permitindo analisar resultados, rating, modalidades, adversários e diferentes períodos da minha trajetória na plataforma.

O DESAFIO

Transformar partidas em informação.

O histórico de partidas contém uma quantidade significativa de informações sobre jogadores, resultados, modalidades, rating e características de cada partida.

O desafio foi consumir esses dados através da API, estruturá-los, realizar as transformações necessárias e construir indicadores capazes de apresentar minha evolução de forma clara e interativa.

IMPLEMENTAÇÃO

Como o projeto foi construído.

Além da análise visual, o projeto envolveu etapas de integração, tratamento, modelagem, atualização e publicação dos dados.

  • Integração com a API do Chess.com: utilizei a API pública da plataforma para coletar meu histórico de partidas, informações dos adversários, resultados, modalidades e dados de rating.
  • Enriquecimento dos dados com a API do World Bank: utilizei a API pública de países do Banco Mundial para construir uma dimensão de países a partir dos códigos ISO dos adversários.
  • Dimensão de países: os dados retornados pela API do World Bank foram tratados para manter o código ISO de duas letras e o nome do país, permitindo relacionar os países aos jogadores encontrados no Chess.com.
  • Análise geográfica dos adversários: a dimensão de países permitiu identificar a origem dos principais adversários e incorporar essa informação às análises do dashboard.
  • Tratamento de dados no Power Query: todo o processo de limpeza, transformação, padronização e preparação dos dados foi realizado utilizando Power Query e linguagem M.
  • Modelagem de dados: os dados foram estruturados e relacionados para permitir análises por período, modalidade, rating, adversário, país e resultado das partidas.
  • Medidas em DAX: foram criadas medidas para quantidade de partidas, vitórias, derrotas, empates, aproveitamento, evolução de rating e demais indicadores utilizados nas análises.
  • Dataflow no Power BI Service: criei um Dataflow para centralizar parte do processo de obtenção e transformação dos dados, com rotina automática de atualização diária.
  • Atualização automática: o modelo semântico e o relatório publicado no Power BI Service possuem rotina de atualização diária para incorporar novas partidas.
  • Publicação no Power BI Service: o dashboard foi publicado online para possibilitar navegação e interação através da web.
  • Integração com meu portfólio: o dashboard foi incorporado diretamente ao meu site através do recurso de embed do Power BI.
  • HTML, CSS e GitHub Pages: meu portfólio foi desenvolvido utilizando HTML e CSS e publicado através do GitHub Pages, com apoio de Inteligência Artificial durante o desenvolvimento e refinamento da interface.

ANÁLISES

O que o dashboard permite analisar.

01

Evolução do Rating

Acompanhamento da evolução do rating registrado ao longo dos meses e anos.

02

Aproveitamento

Análise das taxas de vitórias, derrotas, empates e aproveitamento geral das partidas.

03

Modalidades

Comparação de desempenho em modalidades como Rapid, Blitz, Bullet e Daily.

04

Adversários

Análise do desempenho por faixa de rating, país e perfil dos jogadores enfrentados.
